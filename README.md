## What I'm building

I'm building **[Agent Rails](https://github.com/agent-rails)**, an open-source effort exploring reliable, secure, and observable autonomous AI systems.

**Agent security**

- **[Agent Guard](https://github.com/agent-rails/agent-guard)** — Authorization and audit for AI-agent tool execution. [![PyPI](https://img.shields.io/pypi/v/toolcall-authz?style=flat-square&label=toolcall-authz)](https://pypi.org/project/toolcall-authz/)
- **[Warrant](https://github.com/agent-rails/agent-warrant)** — Signed, scoped, expiring authority grants agents can prove across organizations. [![PyPI](https://img.shields.io/pypi/v/agent-warrant?style=flat-square&label=agent-warrant)](https://pypi.org/project/agent-warrant/)
- **[Bailiff](https://github.com/agent-rails/agent-bailiff)** (in progress) — Checks an agent's delegated authority before each tool call and releases the credential for that one call.
- **[Agent Witness](https://github.com/agent-rails/agent-witness)** — Detects when an agent's account of its actions diverges from the execution record.

**AI infrastructure and observability**

- **[Miniserve](https://github.com/agent-rails/miniserve)** — Experimental LLM serving, KV-cache management, and batching.
- **[MemKit](https://github.com/agent-rails/memkit)** — Self-hosted agent memory and conflict resolution.
- **[Vigilo](https://github.com/agent-rails/vigilo)** — Linux endpoint security and observability.

**Open source contributions**

- **[K8sGPT](https://github.com/k8sgpt-ai/k8sgpt)** — Improvements to AI-response handling, language behavior, and cache invalidation, with regression tests.
